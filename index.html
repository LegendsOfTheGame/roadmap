How to read a card. The first chip names the project. 1 OCT marks a card on the submission path. AFTER marks one placed deliberately after submission, where starting it early costs the date. No marker means the gate does not care either way.

Closed is not a bin. Every card there was decided once, with a reason. The column exists so the decision is visible instead of being made again.

Shipped does not go backwards. What shipped, shipped. A released card cannot return to the planning columns; the only move out of Shipped is into Removed, which records that it was withdrawn and why. Nothing reaches Removed from anywhere else, because nothing can be pulled that was never released.

Characters. Cards that cite a real reading name the character after an ally from the game’s own story. The bugs and the numbers are real; the names stand in.

Moving cards. Drag a card, or use the arrows on it. Your arrangement is kept in this browser only and changes nothing for anyone else. The board itself changes when cards.js changes in the repository.
